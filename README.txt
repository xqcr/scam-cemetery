КИБЕРСТАЯ — ПУБЛИКАЦИЯ НА GITHUB PAGES

1. Создайте на GitHub новый публичный репозиторий, например cyber-pack.
2. Загрузите в корень репозитория всё содержимое этой папки,
   включая папки fonts и assets.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите:
   Source: Deploy from a branch
   Branch: main, папка /(root)
5. Нажмите Save. Через пару минут появится ссылка вида:
   https://ВАШ-ЛОГИН.github.io/cyber-pack/

Сайт не требует сервера, базы данных или платных облачных ресурсов.
